# 💼 Employee Payroll & Attendance Management System

A full-stack web application built with **Python (Flask)** and **CSV persistence** to manage employee payroll, attendance, overtime, and salary calculations.

Built on top of a modular payroll engine that computes:
- Attendance percentage
- Pro-rated earned basic salary
- Overtime pay
- Tax (10%) & Provident Fund (5%) deductions
- Net take-home salary

---

## 🚀 Features

- ✅ **Dashboard** — At-a-glance company payroll metrics
- ✅ **Employee Management** — Add, edit, delete, and list employees
- ✅ **Attendance & Overtime Tracking** — Mark days present and overtime hours
- ✅ **Individual Payslip** — Detailed, printable salary slip per employee
- ✅ **Company Payroll Summary** — Full salary breakdown for all employees with totals
- ✅ **Department Analytics** — Aggregated metrics grouped by department
- ✅ **CSV Persistence** — All data stored in `employees.csv` (auto-loaded on startup)
- ✅ **Responsive UI** — Clean, modern interface with print support
